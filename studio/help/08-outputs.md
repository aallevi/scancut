# Outputs

## Transcriptions for nvim (LaTeX)

Outputs › Transcriptions writes one `.tex` file per source, by date, plus `journal.tex` and a
`scanstudio.sty` with a starting look your own configuration can redefine. The files are
read-only representations: correct the text in Scan Studio and they are rewritten. Each part uses
the same letter as its cut; every entry links back with a `scanstudio://` address.

## Cuts in folders

Outputs › **Export cuts in folders** copies the cuts into a folder of your choice, like Eagle's export:
by place (Chest › Box 24 › Folder 5, each file starting with its number there), by series, or all
together; all cuts, those of the place or series shown, or the selected ones. Same bytes; a file
already there is left alone.

## Eagle

Cuts can also be sent to Eagle when cutting (Settings).
