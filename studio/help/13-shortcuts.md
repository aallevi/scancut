# Keyboard shortcuts

## Editor

| Key | |
|---|---|
| V | Select |
| H, or hold Space | Pan |
| A | Edit points (double-click an edge adds, ⌥-click removes) |
| P | Polygon (Enter closes) |
| M | Rectangle |
| L / K | Lasso / lasso cutting away |
| W | Magic Wand |
| B / E | Brush / eraser |
| X | Swap add and cut (⌥ while clicking does the other) |
| [ ] | Brush size |
| R | Detect in a box |
| S | SAM 3 tool (with SAM 3 chosen) |
| T | Text pane / read a box |
| C | Compare engines |
| O | Cut view |
| Y | Image only (no parts, shading or boxes) |
| G | Loupe |
| Tab | Next part |
| ⌘A | Select all parts |
| ⇧⌘I | Invert |
| Delete | Delete the selected parts |
| ⌘Z / ⇧⌘Z | Undo / redo |
| ⌘S | Cut |
| ⌘0 / ⌘1 | Fit / actual pixels |
| ← → | Previous / next source |

## Window

| Key | |
|---|---|
| ⌘T / ⌘W | New tab / close tab |
| ⌃Tab / ⌃⇧Tab | Next / previous tab |
| ⌘[ ⌘] | Back / forward |
| ⌘, | Settings |
