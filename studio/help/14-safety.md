# Your files are safe

- **A scan is never lost.** It leaves the inbox only once it is safely among the sources.
- **Nothing is overwritten.** A changed cut goes into the history; identical ones stay as they are.
- **Only real pixels.** Pixel-changing tools make separate copies marked "fake pixels".
- **Everything is checked.** Every file has a checksum from the moment it enters; Library › Check
  proves files, cuts and texts match.
- The library keeps snapshots of itself; back it up with the rest of your scans folder (Time
  Machine and an external disk).
